# 宇宙简史与社会演化模型 V1

## 1. 世界起点

- 游戏开始：公元2289年，曲率纪元第7年
- 人类刚掌握早期载人超光速航行，第一批有限民用星际航线准备开放
- 现实理论延伸：太阳系工业、聚变、定向能、自动先驱、低速载人远航、亚光速曲率壳
- 正式起源采用“遗迹催化型突破”：人类完成理论与工业基础，外星遗迹证明新物理存在并提供材料启发，人类经过数十年研究、争夺和事故才完成曲率引擎
- 明确虚构突破：可控制真空相变晶格、宏观受约束负能量、曲率视界控制、全局因果保护
- 超光速不能用于通信；曲率航行受引力井、航线测绘、能源、质量、冷却、偏航和失稳风险约束

## 2. 历史生成总链

`物理规则 -> 天体 -> 生态 -> 物种 -> 认知 -> 文明 -> 制度 -> 科技 -> 太空扩张 -> 文明接触 -> 当前格局`

- 使用“正向演化 + 当前格局约束 + 反向补齐原因”的混合生成
- 所有重大现状必须存在因果来源；无来源设定不得进入正式世界
- 历史以结构化HistoricalEvent和因果图保存，文本仅是事实的一种叙事表现
- 同一事件允许真相、政府叙事、媒体叙事、群体记忆和个人记忆并存

## 3. 时间精度

| 阶段 | 推进尺度 | 永久保存 |
|---|---:|---|
| 宇宙与恒星 | 百万至亿年 | 形成、毁灭、元素与轨道转折 |
| 行星与生命 | 万至百万年 | 气候转折、大灭绝、物种分化 |
| 文明前期 | 百年至千年 | 定居、制度、迁徙、关键技术 |
| 工业与太空时代 | 年至十年 | 国家、产业、战争、扩张 |
| 星际时代 | 月至年 | 航线、殖民、接触、条约 |
| 玩家近期 | 分钟至天 | 人物、新闻、家庭和局部事件 |

稳定时期压缩为区间摘要；只有改变文明方向的节点成为永久事件。

## 4. 科技发展模型

每项技术包含：

- 理论与知识前置
- 材料、能源和制造前置
- 基础设施与人才
- 社会需求和投资来源
- 失败风险与事故历史
- 法律、伦理和政治阻力
- 成本、扩散速度和控制者
- 对其他系统的直接与长期影响

技术不能“研究完成即全社会获得”，必须经历实验、应用、基础设施建设、监管、商业化和社会适应。

## 5. 科技如何改变社会

每次重大技术扩散必须计算以下影响：

| 维度 | 必须回答的问题 |
|---|---|
| 生产 | 谁生产、成本降低多少、哪些岗位消失或诞生 |
| 财富 | 技术和资源由谁拥有，收益如何分配 |
| 政治 | 哪些国家、企业、城市或殖民地获得权力 |
| 家庭 | 生育、寿命、照护、婚姻和代际关系如何变化 |
| 身份 | 地球人、火星人、改造人、AI等身份如何形成 |
| 法律 | 许可、责任、产权、安全和人格权如何调整 |
| 文化 | 宗教、艺术、价值观和社会禁忌如何变化 |
| 战争 | 投送能力、威慑、边界和战争成本如何变化 |
| 日常 | 食物、住房、工作、教育、医疗和旅行如何变化 |

社会反应不是单一结果。相同技术在不同制度中可产生福利普及、财富集中、军事垄断、地方自治或社会冲突。

## 6. 2289年前的科技-社会演化主线

### 2025-2080：自动化与地球调整

- AI提高科研和生产效率，同时造成算力与财富集中
- 气候迁移、粮食和淡水调度推动跨国治理，但没有形成统一世界政府
- 基础收入、公共算力、数据权和AI责任成为长期政治争议

### 2080-2140：太阳系工业化

- 轨道制造、月球工业、聚变能源和小行星资源降低太空活动成本
- 地球国家、技术联盟和自治城市网络将不同治理传统带入太空
- 第一批外生人口形成独立身份；重力差异使“回到地球”对部分人不再可能

### 2140-2210：太阳系分裂与重组

- 地球试图控制能源、航线、AI核心和生殖技术，外部定居点要求自治
- 静海事件与十三日战争留下遗属、法律、禁区、宣传和政治派系
- 太阳系共同体成为松散协调机构，不是统一政府

### 2120-2250：低速星际远航

- 定向能探测器、聚变先驱和自动工厂先于人类抵达邻近恒星
- 世代船、休眠船和胚胎殖民计划形成不同社会实验
- 航行时间以数十年至数百年计，船内形成独立法律、文化与权力结构

### 2210-2282：曲率技术链

- 2198年发现进入太阳系的人工星际遗迹“忒修斯天体”；其规则空腔、人工同位素和异常轨道证明它并非自然天体
- 2204年取回的样本在低温、强磁场与量子纠缠条件下表现出局部真空能和引力异常
- 2206至2221年爆发遗迹样本归属、公开研究、军事封锁和黑市失窃争议
- 2212年长夜信号的数学结构与遗迹激活频谱出现关联，推动深空监听、安全政治和星际投资
- 正能量亚光速曲率壳先用于惯性、辐射和飞船结构保护
- 2236年人类首次复制微观真空泡，证明遗迹效应可以被人类理论和设备重现
- 2258年陈若岚将广义相对论、量子场、遗迹实验和AI拓扑搜索组合为可工程化理论
- 真空相变晶格成为虚构的新物理突破；遗迹是催化剂和线索，不是可直接复制的完整发动机
- 2267年奥菲欧斯事故、后续无人试验和第一次载人折跃形成技术监管、事故遗属和秘密档案
- 2282年第一代载人曲率引擎仍需要少量遗迹材料作为真空相种子，人类尚不能完全替代制造

### 2282-2289：曲率纪元早期

- 后发曲率船可能早于世代船抵达，产生殖民权、救援权和自治权冲突
- 曲率核心产能集中于月球工业与少数企业，引发垄断和走私
- 地球、火星、月球、自由港和远航者后裔对星际扩张拥有不同立场
- 民用航线带来新工作和财富，也制造高风险劳动、信息差、边境投机与新殖民主义
- 外星痕迹尚未等同于确认接触；社会出现守夜、开放接触、宗教重释和商业开发等派别

## 7. 主要社会矛盾

- 旧世界是否拥有新世界
- 曲率核心是公共基础设施、企业财产还是军事武器
- 世代船目的地是否能被后发曲率殖民者重新分配
- 无法适应地球重力的外生人是否仍受地球法律统治
- 高自治AI是否拥有身份、财产和拒绝任务的权利
- 基础生活已高度自动化后，工作是生存条件、社会责任、身份来源还是个人选择
- 外星生命发现应公开、隔离、研究、保护还是商业开发
- 信息不能超光速时，遥远殖民地如何获得合法治理与历史真相
- 遗迹属于发现者、所在地、全人类还是未知制造者
- 使用无法完全理解的外星技术是否构成文明级风险
- 曲率种子材料稀缺时，谁有权决定哪些人、货物和殖民计划能够离开太阳系

## 8. 智慧生命与接触

- 外星物种由母星环境、身体、感官、代谢、繁殖、寿命和认知方式推导，禁止仅做换皮人类
- 通用AgentDrive支持人类、群体意识、生物网络和机器生命的不同需求
- 接触流程：异常发现、确认、观察、解码、远程交流、探测器、实体接触、外交承认
- 文明关系分为了解、信任、恐惧、利益依赖、文化距离、领土、技术差和历史创伤，不使用单一友好度
- 接触必须同时改变科学、军队、市场、宗教、法律、家庭和普通人的日常生活

### 8.1 遗迹时代带来的心理预接触

人类在见到活体外星文明之前，已经经历约九十年的“非人类智慧确定存在”时代。社会不再争论外星智慧是否存在，而争论遗迹代表什么：

- 已灭绝文明留下的普通工业残片
- 主动投放的技术火种
- 观察年轻文明的探测器
- 引诱文明暴露位置的诱饵
- 某个逃亡文明留下的求救或封锁装置

这种长期不确定性形成持续的心理预接触，但不会让第一次接触变得轻松。人类熟悉的是沉默物体，不是一个会提出要求、拒绝合作并拥有自身伦理的活文明。

### 8.2 遗迹时代形成的社会派别

- 开放派：遗迹知识属于所有智慧生命，主张公开研究和主动交流
- 守夜派：遗迹可能是安全测试或诱饵，主张静默、隔离和军事防御
- 继承派：认为发现者有权使用无主遗产，支持快速开发和星际扩张
- 托管派：认为人类无权占有未知文明财产，只能保存、研究并等待所有者
- 超越派：主张利用遗迹技术改造人类，使人类能够理解更高层文明
- 纯人类派：反对文明依赖不可理解的外星技术，要求发展完全独立的替代路线

派别不是单一组织标签；政府、企业、家庭和个人可以在公开、开发、安全、外交等问题上持不同组合立场。

### 8.3 预接触制度

遗迹时代促使人类提前建立：

- 非人类智慧证据分级标准
- 外星物质与信息检疫制度
- 遗迹产权和文明遗产争议法庭
- 跨物种概念与语言研究机构
- 第一次接触授权链和禁止擅自代表全人类条款
- 外星信息污染、机器感染和认知操纵防护规范
- 接触事件公开、延迟公开和紧急封锁的程序
- 外星实体是否具有人格、庇护权、财产权和外交身份的预备法律

这些制度只能降低混乱，不能自动解决代表权问题。地球、火星、月球、自由港、世代船和企业不会天然接受同一个机构代表全人类。

### 8.4 第一次外交的核心冲突

活体文明出现后，最先发生的不应只是“翻译成功并建立大使馆”，而是：

- 对方是否与忒修斯遗迹有关
- 人类使用遗迹材料是否被对方视为研究、盗窃、亵渎或危险拆解
- 谁能代表人类承诺条约
- 对方所谓个体、国家、所有权、死亡和承诺是否与人类概念兼容
- 技术交换是否会破坏双方社会结构
- 是否归还遗迹、停止曲率航行或公开全部研究记录
- 遥远殖民地是否承认太阳系签署的外交协议

第一次外交必须经历：证据确认、隔离观察、概念对齐、有限交流、代表权争议、临时行为协议、互派观察者、长期条约。任一阶段均可因误解、内部派系或第三方行动倒退。

### 8.5 可模拟的接触准备状态

每个地区和组织保存以下摘要变量：

- `AlienExistenceAcceptance`：接受非人类智慧存在的程度
- `RelicTrust`：认为遗迹有益或无害的程度
- `ContactFear`：对活体接触的安全恐惧
- `HumanExceptionalism`：人类中心主义程度
- `OpennessToExchange`：愿意交流技术、文化和人员的程度
- `RepresentationTrust`：相信现有机构能够代表自己的程度
- `ContaminationConcern`：生物、机器和信息污染担忧
- `RelicDependency`：当地经济和基础设施对遗迹技术的依赖

这些变量由历史、新闻、事故、职业、地区利益和个人经历改变，并影响选举、抗议、消费、移民、外交与NPC对话。

## 9. 剧情结构

宏大剧情来自历史压力，不依赖单一拯救宇宙任务：

- 忒修斯遗迹为何进入太阳系、曲率技术来源及长夜信号的联系
- 边界号失踪与不可能提前返回的信号
- 曲率船追上世代船后的自治和殖民权冲突
- 第一次活体智慧文明接触及双方概念误解
- 人类将科学、家庭与自由带向群星，也可能带去垄断、战争和殖民主义

玩家可以从普通职业和家庭生活进入这些历史：船厂工人、医生、维修师、航班乘务员、殖民者、事故遗属、研究员或自由港居民。宏观事件必须通过岗位、价格、新闻、关系、迁移、伤亡和个人选择影响玩家。

### 9.1 分层真相

- 公开历史：人类从忒修斯遗迹获得材料启发，并独立发明曲率引擎
- 保密事实：部分曲率核心必须依赖不可复制的遗迹真空相种子，官方储量和事故率被隐瞒
- 未解问题：遗迹轨道疑似被精确设计，长夜信号可能曾激活它
- 深层剧情保持开放：礼物、火种、观察器、诱饵、求救装置或更古老文明的继承物均可由后续宇宙生成结果决定

深层答案必须在世界种子生成时确定并写入UniverseTruthLedger；游戏表现可以长期只提供不完整证据，不能临时根据剧情需要更换真相。

## 10. 后续系统边界

- `CosmicRuleSet`：物理和因果规则
- `PlanetGenerator`：恒星、行星、气候、地质和资源
- `BiosphereEvolution`：生态和生命演化
- `SpeciesModel`：身体、认知、繁殖和需求
- `CivilizationModel`：制度、经济、文化和内部派系
- `TechnologyDiffusionSystem`：技术研发、控制、扩散和社会影响
- `HistorySimulator`：里程碑、因果图和历史压缩
- `ContactSystem`：发现、翻译、误解与接触阶段
- `DiplomacySystem`：条约、贸易、战争和历史关系
- `UniverseTruthLedger`：宇宙级单源真相

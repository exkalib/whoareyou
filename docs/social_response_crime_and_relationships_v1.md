# 社会感知、执法、调查与关系冲突系统 V1

## 1. 目标

- 玩家和NPC遵守同一套社会规则
- 重大行为必须先被人物或设备感知，信息再通过真实渠道传播
- 社会不能全知；没有证据时组织只能怀疑、调查或保持未知
- 玩家炫耀、隐藏、违法、攻击首府、驾驶外星舰船、帮助他人等行为都能产生对应社会反应
- NPC之间也会因关系、资源、责任、欲望、误解和怨恨产生合作、冲突与犯罪
- 严重行为必须有多重原因，不使用“怨恨达到阈值就自动杀人”的简单触发

## 2. 社会响应总流程

`行为 -> 感知 -> 理解 -> 记录 -> 报告/传播 -> 组织评估 -> 派遣响应 -> 长期社会后果`

每一步都可能失败、延迟、失真或被不同主体解释成不同事件。

## 3. 感知与证据

可能的观察来源：

- 路人、受害者、店员、保安、警察和其他修炼者
- 建筑摄像头、个人AI、车辆、飞船雷达、交通系统和卫星
- 源质、曲率、武器和空间异常传感器
- 现场痕迹、遗体、残骸、身份认证和航行记录

每条证据保存：来源、时间、地点、内容、完整度、可信度、可访问组织和是否已被传播。

证据等级包括低可信传闻、中可信间接记录、高可信独立传感器以及多来源相互验证。调查者不能因为一条模糊记录自动知道真相。

## 4. NPC目击反应

目击者根据危险、勇气、关系、法律信任、个人利益、通讯能力和被发现风险选择：

- 逃跑、躲藏、报警、呼救、拍摄、急救、阻止
- 装作没看见、向帮派报告、勒索、帮助隐藏或错误理解事件

目击不等于必然报警，报警也不等于执法单位瞬间出现。

## 5. 报警与调度

`报告 -> 调度中心 -> 可信度校验 -> 传感器交叉验证 -> 查找可用单位 -> 实际路程抵达`

地区差异：

- 地球核心城市：无人机快速确认，警察数分钟抵达
- 月球工业区：封舱、压力门和安保机器人优先
- 火星自治城：设施控制、社区安保和地方民兵
- 自由港：私人安保、帮派仲裁或无人处理
- 边境殖民地：响应可能以小时计算
- 外星占领区：占领军、代理警察和抵抗组织可能同时介入

## 6. 威胁响应等级

- 一级普通异常：警告、罚款、身份检查和无人机记录
- 二级暴力犯罪：街区封锁、医疗、警察和非致命武器
- 三级超凡威胁：普通人员撤离、修炼者小队、重型无人机和源质抑制
- 四级城市威胁：全城警报、疏散、军队、防空和轨道系统
- 五级文明威胁：谈判、情报、关系评估、联合军事准备和外部文明介入

响应力量必须匹配威胁。普通警察不会无限刷新并冲向能够摧毁舰队的主角。

## 7. 公开炫耀与大型舰船

外星舰船进入行星轨道或城市上空会触发：

- 航线申报、雷达跟踪、交通避让、军事伴飞和检疫要求
- 新闻、公众拍摄、科研分析和市场波动
- 低空噪音、引力、源质与通信影响造成的民事损害责任
- 无视警告后逐级关闭空域、疏散城市和启动防御

合法申报、关闭武器并服从引导时可成为公开访问或外交事件；未授权冲向首府会触发警告、疏散和拦截；明确攻击则升级为城市或文明级事件并永久进入历史。

## 8. 隐藏与调查

玩家可以隐藏身份和行动，但需要承担补给、维修、医疗、通讯、关系和黑市成本。调查组织只能使用真实获得的最后位置、设备记录、采购、关系和行为模式寻找目标。

玩家长期失联时，原工作、住房、家庭和朋友不会冻结；NPC会接替岗位、报告失踪、改变关系并继续生活。

## 9. 案件系统

案件最小结构：

- `CaseId`
- 受害者、最后确认时间和地点
- 报案人、案件类型和优先级
- 证据、目击、嫌疑人和调查假设
- 调查人员、权限、资源和下一行动
- 状态：未报案、失踪、发现遗体、疑似意外、疑似他杀、确定犯罪、锁定嫌疑人、搜捕、审判、悬案、结案

人物失踪可由缺勤、未归家、通讯中断和承诺违约逐步暴露。社会关系越密切、身份越关键，异常越快被发现。

## 10. 侦探NPC

侦探作为普通自主人物执行：

`了解关系 -> 确认最后活动 -> 申请并检查记录 -> 询问人员 -> 分析现场 -> 比较假设 -> 寻找新证据`

侦探需要上班、移动、合作、休息和申请权限，也可能因案件过多、偏见、腐败、战争和资源不足而延误或犯错。

案件可能因证据不足成为悬案，并在新证人、新技术、相似案件、玩家公开能力或NPC重新调查后恢复。

## 11. 连续案件与社会适应

系统可在多个案件间比较地点、时间、受害者特征、源质特征和交通记录，形成模式假设。可信模式可触发：

- 专案组、巡逻、新闻警告和设备升级
- NPC改变出行时间、避免独行、结伴和购买安保
- 公司接送、社区互助、政治压力和错误恐慌

社会会因长期威胁改变生活方式，不只增加一个通缉数值。

## 12. 法律与公众认知

法律由地区和文明规则决定。同一决斗、飞行、武器、伴侣关系和修炼行为可在不同地区获得不同法律评价。

主角社会印象分开保存：身份可信度、知名度、恐惧、尊敬、信任、法律风险、军事威胁、英雄声望、滥杀记录和承诺履行度。不同组织可以同时把主角视为英雄、威胁、嫌犯或合作对象。

## 13. NPC关系模型

人物关系不能只保存单一好感度。关系摘要包括：

- 亲密、信任、吸引、依赖、尊敬、恐惧、嫉妒、怨恨和亏欠
- 共同利益、共同历史、家庭责任和已确认关系边界

伴侣背叛由具体社会制度和双方关系约定定义，不使用跨文明统一的“出轨”标签。

## 14. 冲突与犯罪根因

冲突来源可包括：口角、欺骗、感情边界违反、经济纠纷、工作竞争、权力、嫉妒、长期怨恨、压力和误解。

严重暴力需要多重风险叠加：长期怨恨、当前情绪失控、冲动性、压力、机会、低法律威慑和缺少支持，同时受到同理心、责任、惩罚恐惧、冷静时间、关系和社会介入的抑制。

人格只改变权重，不决定命运。高冲动、高嫉妒或高报复倾向均不等于必然犯罪。

## 15. 冲突升级与替代结果

典型关系冲突可经历：

`怀疑 -> 询问/调查 -> 承认或否认 -> 信任变化 -> 沟通、疏远、分手、调解、法律行动、报复或极少数暴力`

多数矛盾通过沟通、疏远、关系结束、朋友支持、医疗、社区调解和法律方式处理。普通争吵应显著多于打架，打架多于严重伤害，严重伤害多于谋杀。

## 16. NPC犯罪与玩家卷入

NPC犯罪后使用与玩家相同的感知、证据、案件和调查流程。NPC可逃跑、自首、隐瞒、被错误怀疑、被发现或多年未被查明。

玩家可能作为朋友、目击者、调查者、嫌疑人、被嫁祸者、调解者或保护者卷入NPC事件。玩家不参与时，案件仍由NPC推进。

## 17. 模拟规模

- 远处普通关系只保存关系摘要、高风险矛盾和下一关键事件
- 普通争吵压缩为信任、距离和怨恨变化
- 分手、重大纠纷、暴力风险、法律案件、玩家相关人物和组织影响事件才展开详细过程
- 幸福、友谊、忠诚、救助、和解、收养、牺牲和社区互助与恶意事件使用同等的自主事件机制

## 18. 硬性原则

- 玩家和NPC使用同一基本社会响应规则
- 行为未经感知不得自动成为公共知识
- 信息传播有来源、时间、可信度和管辖限制
- 调查可以成功、失败、误判、延迟或成为悬案
- 力量可以逃避抓捕，不能让社会遗忘事实
- 重大死亡、案件、法律结果和社会影响写入TruthLedger
- 自主社会既能产生犯罪与冲突，也必须能够产生稳定关系、帮助和和解

# 宇宙修炼玩法总纲 V1

## 1. 正式类型定位

- 类型：开放宇宙社会模拟 + 科技修炼 + 动态历史 + 第三人称动作角色扮演
- 世界会在主角不参与时继续运行，NPC和组织按照身体、资源、责任、关系、利益和历史自行行动
- 主角拥有受损的高等文明火种系统，但系统只提供观测、推演、训练和知识，不凭空制造资源或替玩家行动
- 现实玩家主要使用鼠标键盘或手柄；游戏世界中的神经接口只是设定，不依赖现实脑机接口
- 世界观允许后期肉身横渡虚空和撕裂空间，但所有能力必须落实为可瞄准、可释放、可取消、可反馈的游戏操作

## 2. 超凡底层规则

- 宇宙存在“源质场”，生命意识与技术设备都可对其进行组织和利用
- 人类曲率引擎是对源质空间效应的低效机械利用
- 修炼必须满足物质、能量和信息来源，不允许无代价提升
- 能力使用消耗源质并造成身体、意识、设备或环境负担
- 星球、物种和文明可发展不同修炼体系；禁止所有外星文明使用同一套人类功法
- 模拟精度可变化，但境界、伤亡、资源消耗、历史和社会后果必须保留

## 3. 系统与远古历史

- 归墟文明尝试把文明意识写入高维源质场，消除个体边界和死亡
- 守界文明发现该过程会持续同化其他生命，双方爆发跨星系战争
- 强行升维失败后，部分意识进入高维、部分碎裂，大量区域出现空间与源质异常
- 主角系统是守界文明留下的受损“文明火种核心”，任务包括保存知识、培养继承者、修复裂隙和阻止归墟碎片复苏
- 守界文明不被设定为绝对正义，归墟文明也不被简化为纯粹邪恶
- 主角因曲率/遗迹事故获得真空相种子，其开放源质结构与受损系统互补，因此成为宿主
- 系统需要主角作为载体继续存在，主角需要系统活过初次适应，两者不是绝对主仆

## 4. 主角六境体系

每个大境界只有初成、稳定、圆满三个阶段。

| 境界 | 核心能力 | 主要可玩范围 |
|---|---|---|
| 感源 | 扫描、强化感官、蓄力、源质闪步 | 建筑、街区 |
| 铸体 | 身体路线、墙面移动、抗性、动作强化 | 城市、设施 |
| 凝核 | 持续飞行、护体、远程技能、四技能槽 | 城市、低空、飞船内部 |
| 成域 | 展开领域、短程空间位移、轨道生存 | 行星轨道、局部舰战 |
| 渡虚 | 肉身太空飞行、空间门、登舰和破舰 | 行星际空间、舰队战 |
| 星界 | 跨行星通道、舰队级领域、航路控制 | 恒星系战略节点 |

- 境界提升优先升级已有操作，不无限增加按键
- 同一闪避键可依次表现为翻滚、源质闪步、残影和穿越空间
- 同一攻击可依次发展为附能、震波、远程释放、领域联动和破舰攻击
- 星界能力通过扫描节点、抵达目标、控制设施和执行大型技能完成，不让玩家直接在菜单中修改恒星

## 5. 操作约束

默认键鼠语义：

- `WASD`移动，鼠标观察和瞄准
- 左键普通/蓄力攻击，右键防御或精确瞄准
- `Q`闪避或空间位移，`E`互动，`F`锁定，`R`系统扫描
- `1-4`四个主动技能，`Z`切换地面/飞行/虚空姿态
- `Shift`冲刺或飞行加速，空格/Ctrl控制飞行升降
- `Tab`系统界面，鼠标中键技能轮盘

任一主动技能必须具备：明确目标、范围预览、消耗、释放反馈、取消或中断规则、世界结果。

## 6. 修炼成长条件

不使用“杀一个敌人增加固定经验值”。每次突破由四项条件构成：

- `体`：身体承载与恢复能力
- `能`：源质储量与能量来源
- `悟`：对功法、敌人和空间规则的理解
- `控`：实际操作与稳定程度

活动贡献：

- 身体训练、医疗重构和伤后恢复提高“体”
- 聚变设施、曲率核心、遗迹和源质材料提高“能”
- 研究、扫描、破解和接触外星体系提高“悟”
- 战斗、技能训练和系统演算提高“控”
- 真实战斗可同时提供身体极限数据、规则理解、控制经验、战利品和社会结果
- 捕获、关闭、说服和破解敌人同样可获得关键数据，禁止以无差别杀戮作为唯一最优升级方式

## 7. 系统加速机制

主角使用“文明火种紧急继承协议”，目标是在先遣舰队抵达前形成战力。

- 完美反馈：实时发现身体损伤、循环浪费和错误动作，消除长期试错
- 后台微循环：行走、工作、进食、睡眠和恢复期间维持安全的基础修炼
- 意识演算：加速动作、技能、飞行和战斗理解，但不能凭空产生身体、能源或材料
- 能量转化：聚变设备可低效转化，曲率核心效率较高，遗迹材料最高但稀缺
- 身体重构：结合人类再生医疗、基因、纳米设备和源质快速完成突破适应
- 系统储备：前期可消耗不可再生的高纯度源质加速，速成越多，后期修复与保护资源越少

系统只懂原理并拥有少量储备，不拥有工厂、政治权限、社会关系和无限材料。

## 8. 标准成长节奏

熟悉流程的玩家在标准模式下约10至20小时达到对抗第一支外星先遣舰队的程度；首次正常游玩约20至35小时。

| 游玩时间 | 目标阶段 |
|---:|---|
| 0-1小时 | 普通身份、工作和日常生活 |
| 1-3小时 | 遗迹事故、系统绑定、感源 |
| 3-6小时 | 铸体与第一条战斗路线 |
| 6-10小时 | 凝核、飞行、四技能槽 |
| 10-14小时 | 成域、轨道活动、破坏小型飞船 |
| 14-18小时 | 渡虚、太空战、登舰 |
| 18-20小时 | 对抗先遣舰队 |

熟练玩家通过高风险、多条件合一的路线缩短时间，而非仅跳过内容。第一幕结束后，系统储备和紧急捷径基本耗尽，成长转向探索、外交、文明建设与更高层战争。

## 9. 敌人与战斗来源

敌人必须回答“为何存在、由谁派遣、想做什么、不处理会怎样”。主要来源：

- 忒修斯遗迹维修、防御和认证回收单元
- 曲率实验造成的空间回响、源质异常和高维碎片
- 企业武装、海盗、走私者、极端组织、非法实验项目和失控修炼者
- 无人机、战斗机器人、自动舰船和失控AI
- 外星侦察器、回收小队、渗透者和后续舰队
- 系统训练空间只提高理解和控制，不提供真实能量、材料或身体提升

## 10. 玩家为什么始终有事可做

世界中的活动由六个来源持续产生：

- 身体产生需求
- 身份产生工作、合同与责任
- 关系产生请求、承诺和冲突
- 组织产生职位、合同和行动
- 社会产生危机、战争、价格和迁移
- 系统产生下一境界所需条件

`Opportunity Compiler`读取真实世界需求，并按照关系、距离、紧迫度、权限、危险、报酬、长期目标和修炼价值筛选少量机会。

系统建议不得凭空生成任务。例如系统发现凝核需要曲率数据，只能指出世界中已经存在的实验船、研究项目、黑市或工作机会。

玩家界面必须能回答：

- 今天已承诺什么
- 收到哪些消息
- 附近有哪些机会
- 自己选择了哪些长期目标
- 系统认为哪些路线可行及风险如何

玩家忽略事件后，NPC、组织和敌人继续行动，任务不冻结。

## 11. 遗产追索事件链

忒修斯遗迹激活后向深空发送未授权使用认证信号。遗迹后继势力将人类视为未授权使用者，初始目标是确认、回收、限制和监管，不以灭绝人类为默认目标。

标准模式世界时间线：

| 世界时间 | 默认事件 |
|---:|---|
| 第0天 | 遗迹激活并发送信号 |
| 第10天 | 外围观测站发现异常 |
| 第25天 | 外星侦察器进入太阳系 |
| 第45天 | 探测器和货船出现失踪 |
| 第70天 | 人类确认外来飞行器 |
| 第90天 | 外交通告抵达 |
| 第105天 | 月球和曲率航道遭封锁 |
| 第120天 | 先遣舰队全面行动 |

- 菜单、说明阅读和玩家现实学习时间不大量推进世界时间
- 睡眠、工作、医疗、修炼重构、旅行和主动等待推进世界时间
- 舰队不按玩家等级暂停或缩放
- 玩家可以通过科研、工作、关系、黑市、系统解析、政治和探索等多个渠道发现威胁
- 越早知道线索越专业，越接近战争迹象越公开；错过早期信息不会强制失败，但准备时间减少

## 12. 第一支先遣舰队

建议基础构成：一艘追索母舰、三艘主力舰、十二艘护卫舰、大量无人机和少量外星高阶个体。

- 足以击败没有准备的当前人类舰队
- 远离母文明、增援缓慢，内部存在追索、观察和继承权派系
- 目标是控制遗迹和曲率技术，因此不会默认直接摧毁太阳系
- 渡虚境且准备充分、操作优秀的玩家可以独自摧毁或制服先遣舰队，但不等于消灭其母文明

## 13. 战争自然演化

关键变量：外星舰队完整度、人类防御、遗迹控制、人类团结、平民存活、主角实力与公开度、外星内部派系、修炼技术扩散。

未击败舰队可能形成：

- 全面占领：曲率和修炼登记、代理政府、遗迹回收、地下抵抗
- 局部分区：月球或航道被占领，地球和火星维持自治，进入长期冷战
- 附属条约：人类保留政府，但接受技术限制、资源义务和外星观察员

失败不是结束。玩家可以隐藏系统、营救人员、偷学技术、组织抵抗、策反外星派系、谈判自治或发动后续解放战争。

击败舰队可能形成：

- 摧毁：主角成为英雄和潜在威胁，外星强硬派获得支持，人类加速军事化
- 俘虏：获得完整技术和战俘，开启人格权、研究权和第一次长期交流
- 谈判：冻结遗迹归属、承认有限自治、交换观察员并共同调查信号来源

战争后组织按资源、控制力、社会支持、外交信任和技术扩散继续决策，不切换到静态结局地图。

## 14. 死亡与战败

- NPC死亡原则上永久，记录时间、地点、原因、遗体、责任、关系、遗产、未完成承诺和信息传播
- 战斗结果包括轻伤、重伤、失能、濒死、被俘、失踪和确认死亡
- 主角生命耗尽首先根据敌方目标进入战败、逮捕、抢劫、撤离或濒死，而非统一死亡画面
- 系统可在不可逆死亡前执行“宿主连续性保护”，封存意识和源核；这属于肉身损毁后的重构，不是时间倒流或死后复活
- 重构消耗设施、生物材料、能源、源质、时间和有限核心；世界、战争、NPC伤亡和任务结果不会重置
- 身体、意识、源核和锚点全部不可恢复时才判定真死

游戏模式：

- 标准模式允许读取关键存档
- 传承模式允许接管孩子、徒弟、同伴或新宿主，继承部分关系、设施和知识
- 铁人模式限制读档，真死结束当前人物但世界可以继续

## 15. 难度与倍率

标准模式是所有底层数值的`1.0×`基准。若标准体验过慢，应调整基准值，禁止用隐藏的1.25倍补偿。

| 模式 | 修炼速度 | 资源获取 | 死亡代价 |
|---|---:|---:|---:|
| 故事 | 2.0× | 2.0× | 0.25× |
| 轻松 | 1.5× | 1.5× | 0.5× |
| 标准 | 1.0× | 1.0× | 1.0× |
| 生存 | 0.7× | 0.65× | 1.5× |
| 极限 | 0.5× | 0.5× | 2.0× |

可分别调整修炼、资源经济、战斗AI、身体生存、世界事件、信息提示和死亡规则。难度不得偷偷修改已经发生的死亡、承诺、舰队位置、历史真相、外星目的或NPC认知。

## 16. 第一阶段实现边界

首个可玩原型不直接实现全宇宙。先验证：

- 一个城市/空间港
- 一个工作身份和基础生活循环
- 身体需求与关系消息
- 遗迹事故和系统绑定
- 感源境扫描、攻击、闪避与一个主动技能
- 三类有因果来源的敌人
- Opportunity Compiler提供真实世界机会
- 一个会在玩家忽略后继续演化的地区事件
- 战败后的时间与世界后果

完成这些后，再扩展凝核飞行、行星轨道、先遣舰队和外星社会。

## 17. 社会感知、执法与自主犯罪

- 玩家和NPC使用同一套感知、证据、报警、调度、调查和法律流程
- 社会不能全知；行为必须被人物或设备感知后才能传播
- 报警由目击者、受害者或自动安全系统根据当地规则发出，响应单位从真实位置出发
- 执法强度按普通异常、暴力犯罪、超凡、城市和文明威胁逐级升级
- 大型舰船炫耀、隐藏、冲击首府、当街暴力和长期失踪均产生对应社会与组织响应
- 失踪与死亡建立持久案件，侦探NPC自主调查，案件可结案、误判、失败或成为悬案
- NPC关系使用亲密、信任、吸引、依赖、尊敬、恐惧、嫉妒、怨恨、亏欠和历史事件，不只使用好感度
- NPC之间可以因真实根因发生合作、背叛、纠纷、打架和极少数严重犯罪，但人格与情绪只是权重，不能直接强制犯罪
- 详细规则以`social_response_crime_and_relationships_v1.md`为准
